1. DevOps
DevOps = Development + Operations

It is a software development approach that combines developers and operations teams to build, test, deploy, and maintain applications faster and more reliably.
Advantages Of DevOps:
Faster software delivery
Continuous integration
Continuous deployment
Better collaboration
Fewer production bugs
Automated testing
Easy rollback

CI/CD
CI (Continuous Integration)
Developers frequently merge code into a shared repository.

Whenever code is pushed:
Build starts automatically
Tests run automatically
Bugs are detected early

CD (Continuous Deployment/Delivery)
Automatically deploys tested applications.
